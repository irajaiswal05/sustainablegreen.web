This project is a clean and interactive website built to help people learn about renewable energy and how to live a more sustainable life. The goal is to explain complex topics like clean power and daily green habits using simple English and a friendly design.

The website has the following main sections:

Home: A welcoming introduction to the mission and a quick look at how we help.

Solar: A guide to solar power showing how it is used in cities, farms, and deserts.

Wind: An explanation of wind energy and why it protects the earth.

Storage: A look into how we can save energy for later using advanced technology.

Lifestyle: Everyday tips on how to reduce waste and live a greener life.

Contact: A page where people can reach out for custom advice and community action.

To make the site highly creative and engaging, I added several special features:

Smooth scrolling animations that bring the text and images to life as you move down the page.

An interactive solar calculator that lets users drag a slider to see real-time power generation numbers.

A custom landscape map with glowing, clickable dots that reveal different wind environments.

3D flip-cards and interactive menus to make learning about green habits fun.

Custom data charts to show real global impact numbers clearly.

An animated, rotating earth orbit graphic on the home page.
